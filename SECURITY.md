# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 3.0.x   | Yes       |
| < 3.0   | No        |

## Reporting a Vulnerability

If you discover a security issue in JamesOptimizer (privilege escalation, Named Pipe IPC validation bypass, unsafe registry/service mutation, or profile signature bypass):

1. **Do not** open a public GitHub issue with exploit details.
2. Report privately via GitHub Security Advisories at:
   `https://github.com/jamesgod1461/JamesOptimizer/security/advisories/new`
3. Include the affected version, reproduction steps, and expected vs. actual behavior.

Reports are acknowledged within 72 hours. Once verified, a fix and release advisory will be published via GitHub Releases.
